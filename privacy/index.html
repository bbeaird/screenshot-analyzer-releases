Screenshot Analyzer Privacy Policy

Effective 2026-10-23 · Developer: Brantley Beaird

What stays on this Mac

The app reads screenshots from Photos and never changes them. Text recognition and sorting run on this Mac. Your library and settings are saved on this Mac, an OpenAI key you add is stored in your Keychain, and optional encrypted backups go to a folder you choose.

Usage analytics

On by default. On a new install, nothing is sent until the setup screen has been shown. The app then sends these events to Segment, which passes them to Google Analytics:

  • app_opened, when the app opens
  • screen_view, with screen_name: insights, find, job_search, settings or cleanup
  • report_exported or report_export_failed, after Export → Report

Each event also has app (screenshot-analyzer), platform (macos), app_version, environment (production), session_id (when the app opened), engagement_time_msec (always 1), a timestamp, a random message ID, and a random identifier that is new each launch and never saved. No screenshots, recognized text, file names or library data are sent.

Segment receives each request, so it sees your IP address. The app sets the event's IP field to 0.0.0.0.

To turn it off, use the switch on the setup screen or Settings → General → Share anonymous usage stats. This stops future sends; it does not delete events already sent. See the Segment (Twilio) privacy notice and Google's privacy policy.

Other connections

  • Updates: when you choose Check for Updates, or turn on automatic checks in Settings → Updates (off by default), the app fetches the update feed from GitHub and downloads updates you install. GitHub sees your IP address and standard request headers; no system profile is sent.
  • iCloud Photos: with Download originals from iCloud on (the default, under Scope), Photos downloads from iCloud any screenshot the app needs that is not on this Mac.
  • Cloud analysis (OpenAI): off by default (Settings → Advanced). Only screenshots you confirm are sent to OpenAI, using your own API key: each as a JPEG up to 1,600 pixels with up to 12,000 characters of its recognized text, and store: false.
  • Links: search, calendar and web links open in your browser only when you click them. Search and calendar links include text from that screenshot.
